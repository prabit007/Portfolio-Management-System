# Portfolio Management System

A desktop-based **Portfolio Management System** built with **C++** and **SFML (Simple and Fast Multimedia Library)**. This application provides an interactive, hardware-accelerated graphical user interface (GUI) to track financial assets, manage investment portfolios, and visualize market performance data.

## 🚀 Features

* **Interactive Dashboard:** View real-time asset allocations, overall portfolio value, and investment metrics.
* **Asset Tracking:** Easily buy, sell, and manage diverse asset classes (e.g., stocks, crypto, cash).
* **Transaction History:** Complete ledger detailing historical deposits, withdrawals, and trades.

## 🛠️ Built With

* **Language:** C++ (C++17 or higher recommended)
* **GUI & Graphics:** [SFML](https://sfml-dev.org) - Simple and Fast Multimedia Library
